## 待人工确认问题

- 1.0 是否以治疗后客户运营闭环作为唯一主线。
- 1.0 服务对象是否限定医美机构，还是覆盖泛美业机构。
- “客户档案 / 患者档案”的正式命名和字段边界。
- 复诊提醒、复购提醒、沉睡客户唤醒是否全部进入 1.0。
- 标签 / 分层在 1.0 中是必须项还是简化项。
- SOP / 流程编排在 1.0 中采用固定模板还是轻量配置。
- AI 在 1.0 中是否真实调用模型，还是只做人工辅助占位。
- 企业微信 / 微信在 1.0 中是否真实接入，还是只记录触达建议。
- OneID、SceneID、Event 是否进入 1.0 基础模型。
- API / Webhook、插件化、多来源数据接入是否全部后置。
