## 状态说明

- “已确认方向”表示当前仓库资料中反复出现，属于产品演进方向。
- “待人工确认”表示无法从可见资料中判断是否进入 1.0 或如何落地。
- “后续增强”表示不建议作为 1.0 闭环验证的必要前置。
- “暂不做”仅能由后续人工决策明确，本文件不替用户冻结最终取舍。

## 与产品主线的关系

后期补充功能应服务于客户运营主线，而不是替代主线。

OneID、SceneID、Event、API / Webhook、插件化和 AI Agent 可以增强系统平台化能力，但 1.0 仍应优先回答：医美 / 美业机构能否围绕客户档案、治疗记录、随访、复诊、复购和运营看板形成可执行闭环。

V1-SCOPE-LOCK-01 锁定后，上述后期功能不作为 1.0 阻塞项，也不构成已批准开发项。
