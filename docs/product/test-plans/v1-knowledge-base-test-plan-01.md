# 智美天工 V1 知识库测试计划 01

任务编号：`ZMTG-V1-KNOWLEDGE-BASE-TEST-PLAN-01`

生成日期：2026-06-11

本文档用于把平台知识库、机构知识库、知识库基础设施、权限、租户隔离、审计、低敏、内容版本、发布 / 下架 / 回滚、RAG 前置边界等能力拆成后续可验证的测试断言。本文档是 test-plan-only，不是测试实现，不是 runtime 授权，不是上线准备，不是试点授权，也不是后续任务队列。

## 1. 当前阶段结论

- 智美天工不是 HIS 系统。
- 智美天工是面向医美 / 美业机构的 AI 客户运营中台。
- 当前主线是治疗后客户运营闭环。
- 当前已有内部 demo / 局部 runtime 基础，但 V1 主业务闭环仍未真实端到端跑通。
- 当前知识库尚未产品化。
- 当前平台知识库 / 机构知识库 / 知识库基础设施都未进入 runtime。
- 当前不能接真实 HIS、真实 credential、真实客户数据或真实模型。
- 本文档是 test-plan-only，不是测试实现，不是 runtime 授权。

## 5. 平台知识库测试断言

### 5.1 平台标准项目知识

- 未来测试应断言平台项目知识只能作为标准知识候选。
- 未来测试应断言平台项目知识不得写成医疗诊断。
- 未来测试应断言平台项目知识不得承诺疗效。
- 未来测试应断言平台项目知识不得包含真实客户个案。
- 未来测试应断言平台项目知识不得被视为知识库 runtime 已实现。

### 5.2 平台术后护理知识

- 未来测试应断言术后护理知识只能作为内部辅助知识。
- 未来测试应断言术后护理知识不得替代医生判断。
- 未来测试应断言术后护理知识不得自动触达客户。
- 未来测试应断言术后护理知识不得生成真实任务 / 预约。
- 当前不实现术后护理知识 runtime。

### 5.3 平台 FAQ / SOP / 话术

- 未来测试应断言 FAQ / SOP / 话术只能作为平台标准内容候选。
- 未来测试应断言 FAQ / SOP / 话术不得自动发送给客户。
- 未来测试应断言 FAQ / SOP / 话术不得包含真实客户数据。
- 未来测试应断言 FAQ / SOP / 话术不得包含敏感承诺或疗效保证。
- 当前不实现平台知识分发或自动触达。

### 5.4 风险提示 / 合规禁用词

- 未来测试应断言风险提示只能辅助内部判断。
- 未来测试应断言合规禁用词只能作为测试计划候选。
- 未来测试应断言不得被断言为 runtime enforcement 已实现。
- 未来测试应断言不得输出高敏字段。
- 当前不实现 field whitelist enforcement runtime 或合规 runtime。

### 5.5 发布 / 下架 / 回滚

- 未来测试应断言发布 / 下架 / 回滚只能作为未来知识版本边界。
- 未来测试应断言不得断言真实内容分发已实现。
- 未来测试应断言回滚记录必须低敏。
- 未来测试应断言不得跨租户泄露内容。
- 当前不实现发布、下架、回滚 runtime。

## 6. 机构知识库测试断言

### 6.1 租户隔离

- 未来测试应断言机构知识库只能在当前租户内生效。
- 未来测试应断言不得跨租户引用机构知识。
- 未来测试应断言权限拒绝时不得泄露知识是否存在。
- 未来测试应断言不得把机构知识库当成平台知识库。
- 当前不实现 tenant guard runtime。

### 6.2 机构项目资料

- 未来测试应断言机构项目资料只能作为机构内部知识候选。
- 未来测试应断言机构项目资料不得承诺疗效。
- 未来测试应断言机构项目资料不得替代医疗判断。
- 未来测试应断言机构项目资料不得包含真实客户个案。
- 当前不处理真实机构资料或真实客户数据。

### 6.3 价格 / 套餐说明

- 未来测试应断言价格 / 套餐说明只能作为知识内容边界。
- 未来测试应断言不得实现支付、合同、发票。
- 未来测试应断言不得输出成交承诺。
- 未来测试应断言不得作为真实计费依据。

### 6.4 医生 / 咨询师资料

- 未来测试应断言医生 / 咨询师资料不得被 AI 自动改写成承诺性话术。

- 未来测试应断言机构 SOP / 话术 / FAQ 不得自动触达客户。

- 未来测试应断言机构 SOP / 话术 / FAQ 必须经过机构权限边界。
- 当前不实现机构内容分发、自动触达或营销能力。

## 7. 知识库基础设施测试断言

### 7.1 文件上传边界

- 当前不实现文件上传 runtime。
- 未来测试应禁止真实客户数据文件。
- 未来测试应禁止 credential、HIS raw payload、DB URL、SQL、stack。
- 未来测试应断言上传失败不得暴露外部错误全文。

### 7.2 文档解析边界

- 当前不实现文档解析 runtime。
- 未来测试应断言解析结果必须低敏。
- 未来测试应断言解析失败必须 fallback 到低敏错误。
- 未来测试应断言不得保留完整病历、完整联系方式或高敏原文。

### 7.3 知识版本边界

- 未来测试应断言知识版本必须可追踪。
- 未来测试应断言版本变更必须有低敏摘要。
- 未来测试应断言回滚不得泄露高敏内容。
- 未来测试应断言不得把版本规划写成 runtime 已实现。
- 当前不实现知识版本 runtime。

### 7.4 检索 / RAG 前置边界

- 当前不实现检索 runtime。
- 当前不实现 embedding / 向量库。
- 当前不实现 RAG runtime。
- 未来测试应断言检索必须遵守租户隔离和角色权限。
- 未来测试应断言检索失败必须低敏 fallback。
- 未来测试应断言 AI 不确定时必须拒答或转人工。

### 7.5 知识引用来源边界

- 未来测试应断言知识引用必须包含低敏来源摘要。
- 未来测试应断言不得暴露知识全文或高敏内容。
- 未来测试应断言不得跨租户引用。
- 未来测试应断言不得伪造来源。
- 当前不实现引用来源 runtime。

## 8. 权限与租户隔离测试断言

| 断言方向 | 未来测试应验证 | 当前边界 |
|---|---|---|
| tenant guard | 平台知识和机构知识使用必须遵守租户边界。 | 不实现 tenant guard runtime。 |
| RBAC | 平台角色和机构角色必须按职责边界区分。 | 不实现 RBAC runtime。 |
| 平台角色 | 平台角色只能管理平台知识规划边界。 | 不访问真实客户数据。 |
| 机构角色 | 机构角色只能管理本机构知识规划边界。 | 不访问平台后台。 |
| 平台知识与机构知识的边界 | 平台知识可规划适用租户范围，机构知识只能租户内使用。 | 不跨租户共享机构知识。 |
| 跨租户访问禁止 | 跨租户读取、检索、引用、配置、审核和审计必须被禁止。 | 不泄露对象是否存在。 |
| 权限拒绝不泄露对象详情 | 权限拒绝只能返回低敏拒绝口径。 | 不返回知识标题、内容或版本详情。 |
| feature disabled 不泄露细节 | 功能关闭只能表达能力未开启或不可用。 | 不绕过开关返回真实内容。 |
| quota denied 不泄露细节 | 配额拒绝只能表达超限或不可用。 | 不暴露套餐内部策略。 |
| 知识引用不得跨租户 | 知识引用来源必须限制在授权范围内。 | 不泄露其他租户知识来源。 |
| 审计只保留低敏摘要 | 审计只记录动作类别、结果、低敏原因和来源摘要。 | 不记录高敏原文或 secret。 |
