# V1 知识库 QA 最终验收缺口清单 01

## 当前已完成能力

- 平台端已具备基于已解析知识片段的 mock/local QA 编排入口。
- 机构端已具备在授权可见范围内的只读 QA 入口。
- QA 先召回低敏片段，再生成低敏回答，并返回引用来源。
- 引用来源包含知识库、文件、chunk、片段序号、低敏预览、分数和命中原因。
- QA 请求和结果已进入最小审计记录，记录问题、回答预览、检索模式、引用数量和安全状态。
- tenant / institution 隔离仍由后端 service / repository 层执行。

## 当前仍是 mock/local QA

当前回答由本地 mock/local composer 根据召回片段拼接生成，只用于内部验收知识库问答编排、引用来源、审计和权限边界。

## 未接真实第三方 AI

当前未接 OpenAI、其他第三方 AI、真实模型网关或外部推理服务。系统不保存真实 AI 原始响应，也不承诺生产级回答质量。

## 未做 OCR

当前只复用已解析文本 chunk，不包含 OCR、图片文字识别、扫描件识别或多模态解析能力。

## 未做 runtime ingestion

当前没有进入 knowledge-base runtime ingestion、后台 worker、队列、scheduler 或自动索引流水线。embedding 与 QA 都保持受控 API 触发。

## 后续上线前缺口

- 明确真实模型 provider、密钥治理、调用审计、成本限额和熔断策略。
- 补充回答安全策略，包括拒答规则、敏感信息检测、人工复核和风险分级。
- 建立知识内容审核、发布、下架、回滚与引用版本追踪。
- 补充生产级召回质量评估、引用准确性评估和回归样例集。
- 补齐真实文件解析、OCR 候选方案和失败补偿策略。
- 设计 runtime ingestion、批量索引、重试、死信和可观测性方案，并单独审批。
- 明确机构端角色权限矩阵、QA 用量限制和审计查询入口。
- 完成生产环境数据保留周期、日志脱敏和安全事件响应流程。
