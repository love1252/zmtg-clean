# 知识库 V1 最终验收缺口清单 02

更新日期：2026-06-14

## 当前完成范围

知识库 V1 已形成完整内部闭环：平台端可管理知识库、机构可见范围、文件元数据、解析结果、chunk、关键词检索、mock embedding、向量检索、mock/local QA、引用来源、审计写入与审计查询。

当前 QA 仍是 mock/local QA，用本地可控逻辑基于已召回片段生成低敏回答，不接真实第三方 AI，不读取外部模型服务，不把问答链路变成生产级智能问答。

当前已有用量限制底座：平台端按 tenant 统计当天 `knowledge_qa_audit_logs`，机构端按 tenant + institution 统计当天 `knowledge_qa_audit_logs`，超限时返回中文安全文案并停止召回。

## 当前明确未完成

当前未接真实第三方 AI。

当前未做 OCR。

当前未做 runtime ingestion。

当前未做真实第三方向量数据库。

当前未做训练链路、计费系统、dashboard 聚合、首页 CMS 或首页编辑。

## 上线前仍需补齐

上线前仍需补齐生产级能力，包括真实模型供应商接入方案、安全评估、供应商失败降级、token 与成本观测、审计保留策略、生产级 quota 配置、租户级运维告警、数据脱敏复核、权限矩阵复核、真实文件解析质量评估、灾备与回滚方案。

上线前还需补齐 QA 结果质量验收集、引用准确率评估、人工抽检流程、敏感内容拦截策略、生产监控面板，以及从 mock/local QA 切换到真实服务前的灰度方案。
