# V0.6-INSTITUTION-KB-CARD-UI-REFERENCE-ALIGNMENT-01

日期：2026-07-03

## 背景

本轮基于机构端知识库参考图，补齐机构端知识库卡片 UI / 功能壳。平台端知识库卡片能力已完成，本轮开始补齐机构端呈现层，但不接入页面和真实运行链路。

## 本轮范围

- 新增机构端知识库卡片组件：`src/modules/institution/components/InstitutionKnowledgeBaseCardPanel.tsx`
- 新增组件测试：`src/modules/institution/tests/InstitutionKnowledgeBaseCardPanel.test.tsx`
- 新增本任务说明文档：`docs/product/plans/2026-07-03-v06-institution-kb-card-ui-reference-alignment-01.md`

## UI 内容

组件包含以下卡片区域：

1. 标题区：说明机构知识库用于维护机构内部话术、项目说明、服务流程和培训知识，并明确当前为受控运营视图。
2. 顶部指标卡：知识条目、文件数、已解析 / 待解析、待优化 / 低命中。
3. 左侧知识目录：全部知识、咨询话术、项目资料、术后护理、活动政策、培训资料，支持前端本地选中态切换。
4. 中间知识条目卡片：标题、分类 / 文件夹、状态、更新时间、命中 / 低命中提示、片段数或受控 fallback、摘要。
5. 文件 / 文档卡片：文件名、类型 / 大小、解析状态、解析字符数或受控 fallback、更新时间、错误信息和操作状态。
6. 受控按钮：上传文档、新建知识、新建文件夹、重新解析、重新训练、删除。
7. 检索测试卡片：只读输入壳、示例问题、检索结果区域和禁用按钮。
8. 解析 / 训练任务记录卡片：任务名称、状态、创建时间、更新时间、错误信息和操作说明。
9. 右侧运营建议 / 风险提示卡片：低命中知识、待补充资料、解析失败文件、待训练内容和建议动作。
