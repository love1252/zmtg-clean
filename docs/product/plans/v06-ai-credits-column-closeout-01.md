## 2. 已完成能力

平台端「AI 用量与费用」栏目在 V0.6 阶段已完成以下只读运营分析能力：

1. 账单式总览：以 AI 积分消耗作为主指标，展示调用次数、Token 总量、成功率、峰值日。
2. 全局时间筛选：支持今日、近 7 天、本月、上月、自定义时间范围，并作用于全部页签。
3. 厂商 / 模型统计：展示厂商卡片、模型明细、调用次数、Token、AI 积分、成功率和占比。
4. 日期趋势：以轻量趋势图展示每日调用次数、Token 总量、AI 积分消耗。
5. 单日模型构成：按选中日期展示模型消耗构成。
6. 租户用量排行：展示租户低敏标识、调用次数、Token、AI 积分、成功率和计量状态。
7. 服务项目消耗：展示服务项目、服务分类、调用来源、动作、版本、调用次数、成功率、Token、AI 积分和计量状态。
8. 计量状态：展示已计量、待计量、不计费等状态的运营统计。
9. 明细记录：展示平台端低敏明细字段，并保留返回条数控制。

## 7. 低敏边界

平台端允许展示：

1. provider / model code。
2. 厂商展示名。
3. 厂商 Logo 或 Logo 文本。
4. 模型展示名。
5. Token 汇总。
6. AI 积分消耗。
7. 调用次数。
8. 成功率。
9. 计量状态。
10. 租户低敏标识。
11. 服务项目低敏归因字段：serviceCategory、serviceName、serviceSource、serviceAction、serviceVersion。

平台端严禁展示：

1. `apiKey` / `encryptedApiKey`。
2. `baseUrl`。
3. Authorization / Cookie / Token 凭据。
4. prompt / question。
5. answer。
6. rawResponse。
7. signedUrl / storageKey。
8. metadata 原样 JSON。
9. meteringDetails 原样 JSON。
10. RAG source 原文。
11. 客户姓名。
12. 手机号。
13. 身份证。
14. 病历详情。
15. `.env.local`。
16. 数据库连接串、密码、密钥。
17. RMB、`¥`、人民币金额、真实成本。

机构端默认不展示内部 provider、model、Token、AI Credits 折算规则或成本信息。是否向机构端展示服务项目统计，需后续独立产品决策和授权。
