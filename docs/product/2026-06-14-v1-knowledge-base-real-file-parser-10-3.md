# 知识库真实文件解析生产化 10-3

> 日期：2026-06-14  
> 范围：知识库上传文件的本地文本解析、解析状态、chunk 预览和低敏展示边界。

## 支持的文件类型

当前平台端知识库文件解析支持以下上传文件：

- `.txt`：按 UTF-8 文本解析。
- `.md`：按 UTF-8 Markdown 文本解析。
- `.csv`：按 CSV 行列解析，输出为低敏表格文本预览。
- `.pdf`：仅支持文本型 PDF 中可直接提取的文本操作符内容。
- `.docx`：读取 Office Open XML 包中的 `word/document.xml` 文本。
- `.xlsx`：读取 Office Open XML 包中的工作表和共享字符串文本。

文件类型同时受扩展名和 MIME 白名单约束。不支持的类型会直接失败，不读取文件正文。

## 不支持 OCR 和扫描 PDF

本任务不接入 OCR、图片识别或扫描 PDF 文字识别。

如果 PDF 只有图片、扫描页或无法从文本流中提取内容，解析会安全失败，失败文案为：

`文件未提取到可解析文本，扫描件或图片内容暂不支持`

## 文件大小和内容长度限制

- 上传文件大小限制沿用现有知识库文件管理限制：单文件最大 `20MB`。
- 解析服务也会在读取正文前校验文件记录大小，超过限制时失败，文案为：
  `文件大小超过解析限制，请拆分后重新上传`
- 解析后的文本最多保留 `32000` 字符，超过后截断为低敏预览，并在解析记录中标记：
  - `failureReasonCode`: `content_truncated`
  - `safeFailureMessage`: `解析文本超过长度限制，已截断为低敏预览`

## 解析失败行为

解析失败只返回中文安全文案，不返回第三方库错误、stack trace、SQL、storageKey、本地路径、token、secret 或 API key。

当前安全失败类型：

- 不支持文件类型：`当前文件类型暂不支持解析`
- 文件过大：`文件大小超过解析限制，请拆分后重新上传`
- 空文本、扫描 PDF 或图片内容：`文件未提取到可解析文本，扫描件或图片内容暂不支持`
- 底层读取、格式或写入异常：`知识库文件解析失败，请稍后重试`

失败时会清空旧 chunk，避免旧片段被误认为新解析结果。

## chunk 机制

解析后的文本继续复用现有 `chunkV1KnowledgeBaseRuntimeDocument` 切分机制，并按平台端解析预览限制生成 chunk 摘要。

本任务没有新增 ingestion worker、queue、scheduler、runtime ingestion 或真实向量库。

## 平台端低敏展示边界

平台端可以看到：

- 文件名、类型、大小、解析状态。
- 解析字符数、chunk 数。
- 安全失败文案。
- chunk 低敏预览。

平台端不得展示：

- 解析全文。
- `storageKey`、本地路径、SQL、stack trace。
- token、secret、API key。
- 真实向量、训练内容或后台内部错误。

## 机构端只读展示边界

机构端只能读取已授权、已发布且当前机构可见的知识库文件解析状态和 chunk 低敏预览。

机构端不得发起解析、上传、归档、训练或生成向量索引，也不得看到全文、`storageKey`、本地路径、SQL、stack trace、token、secret 或 API key。

跨 tenant、跨机构不可见规则继续由现有服务校验。

## 新增依赖说明

本任务未新增 npm 依赖。

当前 PDF、DOCX、XLSX、CSV 文本解析均为本地实现，只使用 Node.js 标准能力读取字节、zip 和压缩内容：

- 用途：解析常见文本类上传文件。
- 风险：本地解析器只覆盖文本型 PDF 和常见 Office Open XML 文本结构，不覆盖复杂排版、图片、扫描件、加密文件或损坏文件。
- 替代方案：后续如需更高格式覆盖率，可单独评审引入轻量本地解析依赖；仍不得接入 OCR、真实 AI、外部网络服务或真实向量数据库。

## 仍然禁止

本任务仍明确禁止：

- OCR。
- 扫描 PDF / 图片文字识别。
- 真实 AI provider。
- 读取、写入或使用任何真实 API key。
- 外部网络服务调用。
- 真实向量数据库。
- runtime ingestion。
- worker / queue / scheduler。
- 训练系统、计费系统和 dashboard 聚合。
