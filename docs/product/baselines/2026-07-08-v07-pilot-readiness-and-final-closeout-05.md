本文不开发功能，不接真实企业微信，不接真实短信，不接真实 HIS，不接真实 webhook，不读取或写入真实渠道 secret / API key，不真实发送消息，也不真实出网。

## 5. 当前可演示主链路

当前只支持内部受控演示，主链路为：

消息草稿
-> 人工确认
-> 触达安全治理
-> MessageDelivery mock 状态
-> 企业微信授权状态 mock
-> 企业微信客户联系 mock
-> 企业微信随访触达 mock
-> timeline 低敏沉淀
-> audit 低敏审计
-> dashboard 低敏统计。

该链路可以演示“消息需要人工确认、触达需要安全治理、外部渠道默认不真实发送、状态可被低敏记录和汇总”的产品闭环。

该链路不能演示真实企业微信发送、真实短信发送、真实客户同步、真实聊天记录同步或生产级渠道触达。

## 6. 企业微信客户运营 mock 链路现状

当前企业微信客户运营链路仍为 mock：

- 企业微信授权状态为 mock。
- 企业微信客户联系为 mock。
- 企业微信外部联系人为 mock。
- 客户归属员工关系为 mock。
- 企业微信随访触达为 mock。
- allowRealSend 必须保持 false。
- externalChannelEnabled 必须保持 false。
- mock_sent 只表示本地 mock 状态成功写回，不表示真实消息已发送。
- mock_failed 只表示本地 mock 状态失败，不表示真实企业微信接口失败。
- skipped 表示因前置条件不满足而跳过。
- external_disabled 表示外部渠道未启用。

当前方向是企业微信客户运营接入，不是企业微信登录，不是机构员工扫码登录智美天工，不是个人微信好友同步，也不是普通微信聊天记录同步。

## 7. MessageDelivery / timeline / audit / dashboard 当前能力

MessageDelivery 当前能力：

- 可作为人工确认后的受控发送记录。
- 可承载 mock_sent、mock_failed、skipped、external_disabled 等低敏状态。
- 可表达企业微信 mock 触达结果，但不调用真实企业微信接口。

timeline 当前能力：

- 可沉淀消息草稿、人工确认、mock 触达、跳过、失败和外部禁用等低敏事件。
- 不展示真实手机号、身份证、病历号、真实 external_userid、完整聊天内容或原始接口返回。

audit 当前能力：

- 可记录触达安全治理原因、授权不可用、客户联系不可用、mock 触达生成和 mock 触达结果。
- 不记录真实渠道 secret / API key，不记录真实 webhook payload。

dashboard 当前能力：

- 可汇总消息草稿、受控发送、企业微信授权 mock、客户联系 mock、企业微信触达 mock 和低敏状态统计。
- 当前只能用于内部受控演示和准试点准备判断，不能作为生产级运营看板。

## 11. 试点前置条件清单

后续如要进入真实试点，必须先满足：

- 明确测试企业微信主体。
- 明确是否走企业微信服务商 / 第三方应用。
- 明确单租户、单机构、单员工、单客户、单条消息。
- 明确测试客户，不得误发真实客户。
- 明确客户授权和员工知情。
- 明确数据脱敏和权限边界。
- 明确人工确认机制。
- 明确 MessageDelivery 状态回写。
- 明确 timeline / audit / dashboard 审计链路。
- 明确灰度开关。
- 明确回滚开关。
- 明确真实 secret 管理方案。
- 明确 webhook 安全边界。
- 明确不做客户自动回复。
- 明确不做群发。
- 明确不做真实聊天记录同步。
- 明确出现异常时立即关闭真实渠道。

未完成以上前置条件前，不得启动真实客户、真实消息或真实渠道灰度。

## 12. 内部受控演示条件

当前可以进入内部受控演示，但必须满足：

- 只使用本地或受控演示环境。
- 只使用 mock 数据和低敏数据。
- 不连接真实企业微信、短信、HIS 或 webhook。
- 不读取真实渠道 secret / API key。
- 不发送真实消息。
- 不真实出网测试。
- 明确告知演示对象当前仅为 mock 闭环。
- 演示材料必须保留“不能对外宣称”的边界。

内部受控演示的目标是验证产品链路、低敏状态表达和人工确认流程，不是验证真实渠道可用性。

当前可以进入准试点准备，但准备内容只能包括：

- 试点机构候选确认。

- webhook 安全边界设计。

准试点准备不等于真实试点启动，不允许顺手接真实接口、真实客户、真实消息或会话内容存档。

## 14. 真实试点禁止直接启动的原因

当前不能直接启动真实试点，原因是：

- 企业微信仍为 mock，未完成真实授权接入。
- 客户联系仍为 mock，未同步真实外部联系人。
- 企业微信触达仍为 mock，未发送真实消息。
- 会话内容存档未接入，也未完成合规边界。
- 真实渠道 secret / API key 未纳入安全管理方案。
- webhook 安全边界未完成真实验收。
- 客户授权和员工知情未完成试点确认。
- 真实灰度范围、回滚开关和异常关闭机制尚未在真实环境验收。
- 当前 dashboard 只能支撑低敏演示统计，不能支撑生产级合规审计。

因此，V0.7 closeout 之后可以设计真实试点方案，但不能直接进入真实企业微信接入、真实客户同步、真实消息发送、会话内容存档或生产上线。

## 15. 后续建议任务

后续建议只作为规划，不代表开发许可：

- 真实试点方案设计：明确试点机构、测试主体、灰度范围、合规边界和回滚方案。
- 企业微信服务商 / 第三方应用路径评估：确认是否申请、何时申请、由谁授权、授权范围是什么。
- 真实授权状态 proof 设计：限定单租户、单机构、单员工。
- 真实客户联系同步 proof 设计：限定单客户、低敏字段白名单和撤销策略。
- 单条真实消息 proof 设计：必须人工确认，必须 MessageDelivery，必须可回滚。
- 会话内容存档独立规划：单独处理企业授权、员工知情、客户边界、内容脱敏、权限控制、审计、保留、删除和导出。

后续任务不得从自动营销、自动群发、客户自动回复或 AI 自动直接发送客户可见建议开始。
