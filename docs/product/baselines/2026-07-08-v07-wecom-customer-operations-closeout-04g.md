# V0.7 企业微信客户运营接入阶段收口

## 1. 文档目的

本文用于收口 V0.7 企业微信客户运营接入阶段的 mock 成果，并明确会话内容存档边界。

本阶段只完成企业微信客户运营方向、授权状态、客户联系、随访触达和状态回写的低敏 mock 闭环，不代表真实企业微信已经接入，也不代表会话内容存档已经接入。

## 2. 当前 V0.7 企业微信接入进度

V0.7 已完成从方向修正到 mock 闭环的阶段性建设：

- 企业微信客户运营方向修正：明确不是企业微信登录。
- 企业微信授权接入契约文档。
- 企业微信授权状态 mock 模型。
- 企业微信客户联系 mock 同步基础闭环。
- 企业微信随访触达 mock 适配与状态回写。
- 企业微信 mock 触达状态进入 MessageDelivery。
- timeline / audit / dashboard 可见低敏状态。
- 页面可见“不是企业微信登录”“不是个人微信好友同步”“不是聊天记录同步”“当前仅 mock”“未接真实企业微信”“不真实发送”“不真实出网”。

## 3. 已完成能力清单

已完成能力只限 mock 与低敏展示：

- 授权状态 mock：可展示机构企业微信客户运营授权状态、授权能力范围和默认关闭边界。
- 客户联系 mock 同步：可展示企业微信客户联系、外部联系人、客户归属员工、标签、备注、来源和系统客户关联的低敏摘要。
- 企业微信随访触达 mock：可在人工确认和安全治理之后生成 mock 触达状态。
- MessageDelivery 状态回写：企业微信 mock 触达进入 MessageDelivery，并可表达 mock_sent、mock_failed、skipped、external_disabled。
- timeline 低敏事件：可展示企业微信 mock 触达生成、成功、失败、跳过或外部禁用的低敏事件。
- audit 低敏原因：可记录授权不可用、客户联系不可用、mock 触达生成和 mock 触达结果。
- dashboard 汇总：可展示授权状态、客户联系 mock 同步、企业微信 mock 触达统计和低敏空态。

## 4. 当前可演示主链路

当前可演示的主链路为：

治疗摘要 -> 随访路径 -> 阶段任务 -> 消息草稿 -> 人工确认 -> 触达安全治理 -> 企业微信授权状态 mock 检查 -> 企业微信客户联系 mock 关系检查 -> MessageDelivery -> 企业微信 mock 触达 -> mock 状态回写 -> timeline / audit / dashboard 汇总。

该链路只证明本地 mock 状态闭环，不证明真实企业微信消息可发送。

## 5. 当前仍是 mock 的能力

以下能力当前仍是 mock：

- 企业微信授权状态。
- 企业微信客户联系同步。
- 企业微信外部联系人关系。
- 客户归属员工映射。
- 企业微信随访触达。
- MessageDelivery 中的企业微信触达状态。
- timeline / audit / dashboard 中的企业微信相关展示。

当前 allowRealSend 必须为 false，externalChannelEnabled 必须为 false。即使页面显示 mock_sent，也只表示本地 mock 状态写回，不表示真实企业微信消息已发送。

## 6. 会话内容存档边界

会话内容存档不是普通聊天记录同步，也不是把客户聊天内容直接搬到系统里展示。

当前阶段没有接入会话内容存档，没有同步任何真实聊天记录，没有读取客户聊天内容，没有客户自动回复，也不允许 AI 自动分析并回复客户。

会话内容存档属于独立高风险能力，涉及企业授权、员工知情、客户合规边界、内容脱敏、权限控制、审计、数据保留、删除与导出策略，以及医疗建议风险控制。它不属于当前 mock 接入范围。

## 7. 会话内容存档后续准入条件

后续如要接入会话内容存档，必须单独立项、单独授权、单独设计、单独验收，并至少满足：

- 企业授权。
- 员工知情。
- 客户合规边界。
- 内容脱敏。
- 权限控制。
- 审计。
- 数据保留期限。
- 删除策略。
- 导出策略。
- 敏感词与医疗建议风险控制。
- AI 只辅助员工，不直接自动回复客户。

未满足以上条件前，不得宣称或实现会话内容存档。

## 8. 当前不能宣称的能力

当前不能宣称：

- 真实企业微信已接入。
- 企业微信服务商已申请完成。
- 真实客户联系已同步。
- 真实外部联系人已同步。
- 真实聊天记录已同步。
- 会话内容存档已完成。
- 企业微信真实消息已发送。
- 客户自动回复已完成。
- 自动营销群发已完成。
- AI 自动生成并直接发送客户可见医疗建议。
- 生产级渠道触达上线。
- 生产级合规审计完成。

## 9. 真实企业微信接入前置条件

进入真实企业微信灰度前，必须先明确：

- 测试企业微信主体。
- 是否走服务商 / 第三方应用。
- 单租户、单机构、单员工、单客户、单条消息。
- 测试客户，不得误发真实客户。
- 授权范围。
- 回滚开关。
- 人工确认流程。
- MessageDelivery 状态回写。
- timeline / audit / dashboard 审计链路。
- 不做客户自动回复。
- 不做群发。
- 不做真实聊天记录同步。

## 10. 真实客户联系同步前置条件

真实客户联系同步前，必须明确：

- 授权主体和授权范围。
- tenantId、institutionId 与企业微信主体的绑定关系。
- customerId 与 external_userid 的低敏映射策略。
- 员工 userid 与系统员工的映射策略。
- 标签、备注、来源的低敏字段白名单。
- 不展示真实手机号、身份证、病历号、完整聊天内容、原始接口返回和密钥参数。
- 同步失败、撤销授权、过期授权和禁用状态的回滚策略。

真实客户联系同步不等于个人微信好友同步。

## 11. 真实随访触达前置条件

真实随访触达前，必须满足：

- 机构企业微信授权有效。
- 客户联系关系可用。
- 员工归属关系可用。
- 客户 consent 可用。
- 客户未 opt-out。
- frequency cap 未命中。
- 当前租户和机构进入灰度。
- 人工确认已完成。
- MessageDelivery 已生成。
- allowRealSend 的真实启用必须单独审批。
- externalChannelEnabled 的真实启用必须单独审批。
- 失败、撤回、禁用和回滚都能进入 timeline / audit / dashboard。

真实随访触达不是自动营销，不允许自动群发。

## 12. 数据安全与低敏边界

当前低敏边界为：

- 不展示真实 corpId。
- 不展示真实 external_userid。
- 不展示真实 userid。
- 不展示真实手机号。
- 不展示身份证。
- 不展示病历号。
- 不展示完整聊天记录。
- 不展示企业微信原始接口返回。
- 不展示真实 webhook 内容。
- 不展示真实渠道 secret 或 API key。
- 不展示数据库连接串。

页面、API 和文档只能展示低敏状态、低敏摘要、mock 标识和受控状态码。

## 13. timeline / audit / dashboard 当前可见内容

timeline 当前可见：

- 企业微信 mock 触达记录已生成。
- 企业微信 mock 触达成功或失败。
- 企业微信客户联系关系不可用时已跳过。
- 企业微信外部通道未启用时 external_disabled。

audit 当前可见：

- 企业微信授权状态读取或不可用。
- 企业微信客户联系关系不可用。
- 企业微信 mock 触达生成。
- 企业微信 mock 触达结果。

dashboard 当前可见：

- 授权状态 mock。
- 客户联系 mock 同步状态。
- 企业微信 mock 触达统计。
- mock_sent、mock_failed、skipped、external_disabled 的低敏汇总。

## 14. 与 MessageDelivery 的关系

企业微信随访触达必须接在 MessageDelivery 之后。

MessageDelivery 是人工确认后的受控发送记录。当前企业微信 mock 触达通过 MessageDelivery 回写状态，但不真实发送，不真实出网，不调用真实企业微信接口。

当前 mock_sent 只表示本地 mock 成功；mock_failed 只表示本地 mock 失败；skipped 表示因授权、客户联系、安全治理或其他前置条件不满足而跳过；external_disabled 表示外部通道未启用。

## 15. 后续目标 5 建议

后续目标 5 可以拆为：

- 真实企业微信灰度前置评审：确认测试主体、授权模式、灰度范围和回滚方案。
- 企业微信服务商 / 第三方应用可行性评估：只做评估，不直接接真实接口。
- 单机构真实授权 proof：限定单租户、单机构、单员工、单客户。
- 单条真实消息 proof：必须人工确认，必须有 MessageDelivery，必须可回滚。
- 会话内容存档独立方案：单独评审合规、隐私、权限、审计、保留与删除策略。

目标 5 不应从自动营销、自动群发或客户自动回复开始。

## 16. V0.7 企业微信客户运营接入是否可 closeout 的结论

V0.7 企业微信客户运营接入可以按 mock 阶段 closeout。

closeout 结论仅限：

- 方向已修正为企业微信客户运营接入，不是企业微信登录。
- 授权状态、客户联系、随访触达、MessageDelivery、timeline、audit、dashboard 已形成低敏 mock 闭环。
- 当前没有真实企业微信接入。
- 当前没有真实客户联系同步。
- 当前没有真实聊天记录同步。
- 当前没有会话内容存档。
- 当前没有真实发送、真实出网、真实 webhook、自动营销群发或客户自动回复。

后续如进入真实灰度，必须重新授权、重新设计、重新验收。
