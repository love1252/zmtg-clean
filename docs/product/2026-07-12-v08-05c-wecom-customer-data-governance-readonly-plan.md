# V0.8 05C 企业微信客户运营数据治理 / 外部联系人同步只读规划

## 1. 结论摘要

05C 是企业微信客户运营数据治理与外部联系人同步的**只读规划阶段**。本阶段不做真实同步，不调用企业微信，不读取会话内容，也不接入会话内容存档。

本阶段目标是定义数据边界、字段白名单、租户隔离、客户匹配、授权状态、审计、人工确认和后续最小开发切片。05C 不能继承 05B 的真实 proof 节奏而直接进入真实外部调用。

## 2. 05C 产品目标

- 规划机构客户运营的“企业微信外部联系人只读视图”。
- 规划后续将企业微信外部联系人与系统客户档案进行低敏匹配的边界。
- 规划运营人员可查看的归属员工、标签、来源、备注、关联状态与可随访状态。
- 规划平台端的租户授权状态、字段白名单、同步状态与审计状态治理视图。
- 为后续真实同步能力定义安全边界，而非在本阶段实现真实同步。

## 3. 非目标范围

- 不做企业微信登录。
- 不申请企业微信服务商能力。
- 不接入会话内容存档。
- 不读取聊天记录。
- 不同步真实客户数据。
- 不创建真实客户。
- 不写入生产数据库。
- 不运行 migration。
- 不自动发送消息。
- 不继续 `send_result` 轮询。
- 不把外部联系人同步做成自动营销链路。

## 4. 数据对象规划

以下对象仅作为后续数据契约规划，不代表已实现或已接入真实数据：

- **WeCom tenant authorization**：机构企业微信授权状态。
- **WeCom external contact**：外部联系人只读资料。
- **WeCom follow user**：归属员工。
- **WeCom customer mapping**：外部联系人与系统客户的候选匹配。
- **WeCom customer tag**：企业微信标签。
- **WeCom sync snapshot**：同步批次快照。
- **WeCom audit event**：审计事件。
- **WeCom manual review**：人工复核状态。

## 5. 字段白名单、低敏字段与禁止字段

### 允许低敏展示字段

- 外部联系人展示名。
- 企业微信 external_userid 的脱敏值或 digest。
- 归属员工展示名。
- 归属员工 userid 的脱敏值或 digest。
- 标签名称。
- 来源类型。
- 添加时间的日期级展示。
- 备注的低敏摘要。
- 与系统客户的匹配状态。
- 最近同步时间。
- 同步状态。
- 人工复核状态。

### 低敏处理原则

- 标识符只规划使用 digest、hash 或其他不可逆低敏标识。
- 日期默认只规划展示到业务所需粒度。
- 摘要不得承载聊天原文、证件信息或联系方式原文。
- 字段白名单应由租户授权、产品场景和审计规则共同约束。

### 禁止字段

- access_token。
- secret。
- 原始 external_userid。
- 原始 userid。
- 原始手机号。
- 身份证号。
- 原始聊天内容。
- 会话内容存档密钥。
- 客户完整敏感资料。
- 未脱敏 webhook payload。
- 原始 API response 的全量落库或前端展示。

## 6. 租户隔离与授权状态

- 每个机构只能查看自己的企业微信授权与外部联系人视图。
- 平台端只能查看治理状态和低敏摘要。
- 机构端只能查看自身授权下的低敏客户运营资料。
- 授权状态至少规划为：未配置、已授权、已撤销、已过期、禁用、外部能力关闭、待人工复核。
- provider 默认保持 disabled / fail-closed。
- 没有明确授权时，不能同步，也不能展示真实外部联系人。

## 7. 客户匹配规则

- 第一阶段只允许 mock / demo 数据匹配。
- 不使用手机号明文做直接展示。
- 可规划 digest、hash 或低敏标识匹配。
- 匹配结果必须带有置信度或状态。
- 自动匹配不能直接覆盖客户档案。
- 低置信度匹配必须进入人工复核。
- 解除匹配必须记录审计。

## 8. 同步与审计边界

- 真实同步不属于本任务范围。
- 后续若做同步，必须限定租户、限定授权、限定字段与限定批次。
- 每次同步必须写入 audit event。
- 不允许宽范围拉取。
- 不允许无租户边界同步。
- 不允许原始 response 全量展示。
- 同步失败不得写成功态。
- 人工复核状态不得被自动覆盖。

## 9. 机构端 / 平台端只读视图规划

### 机构端

- 企业微信授权状态卡片。
- 外部联系人低敏列表。
- 客户匹配状态。
- 标签与归属员工摘要。
- 最近同步状态。
- 人工复核入口。
- 禁止展示敏感字段。

### 平台端

- 租户授权状态总览。
- 外部能力开关。
- 同步健康状态。
- 异常租户列表。
- 字段白名单治理。
- 审计摘要。
- 禁止查看客户敏感明细。
