## 10-6 任务目标

10-6 将知识库当前阶段整理为可交付、可试用、可验收、可交接的内部发布包。当前版本只开放低敏、授权、mock/local 能力，不进入真实 AI、OCR、真实向量库、runtime ingestion 或后台队列开发。

## 当前已完成能力总清单

- 文件上传：平台端可受控上传白名单文本类文件。
- 真实文本文件解析：支持 txt、md、csv、文本型 pdf、docx、xlsx。
- chunk 预览：复用现有切分机制，只展示低敏片段预览。
- 关键词检索：基于已解析 chunk 进行关键词召回。
- mock 向量检索：使用 deterministic mock embedding 验证相似召回。
- mock/local QA：基于召回片段生成本地回答，不调用真实 AI。
- citations：展示回答引用的低敏片段来源。
- QA audit：记录低敏问答审计。
- quota：保留 tenant 与 institution 每日次数限制。
- capability：展示能力启用状态、禁用原因和进入条件。
- 平台端低敏展示：按 tenant 范围展示发布状态、清单、手册、验收模板和边界。
- 机构端只读低敏展示：按授权范围只读展示交付状态、操作摘要和验收要点。

## 平台端内部试用操作手册

1. 确认发布状态和 No-Go：进入平台端知识库管理界面，先核对发布状态、禁用能力和禁止外显字段。
2. 按白名单上传并解析文件：使用 txt、md、csv、文本型 pdf、docx、xlsx 样本验证解析成功和安全失败。
3. 核对 chunk、检索、QA 与引用：查看低敏 chunk，执行关键词检索、mock 向量检索和 mock/local QA。
4. 记录 audit、quota 与失败态：记录 citations、QA audit、quota、capability 和中文失败态。

平台端试用时必须确认发布包清单完整，包括阶段总交付说明、平台端内部试用操作手册、机构端只读试用操作手册、内部验收报告模板、已完成能力与 No-Go 清单、后续进入条件说明。

## 机构端只读试用操作手册

1. 确认只读交付状态：先确认机构端只读交付状态和授权范围。
2. 查看授权知识库和文件解析状态：只读查看授权知识库、授权文件、解析状态和 chunk 预览。
3. 完成只读检索、QA 与 citations：在授权范围内完成关键词检索、mock 向量检索、mock/local QA 和引用核对。
4. 记录只读边界和失败态：记录不可操作入口、权限失败、quota 超限、无引用和无检索结果。

机构端不得出现上传、归档、发起解析、训练、生成 embedding、管理 visibility、真实 AI、OCR、真实向量库、runtime ingestion 的操作入口。

## 内部验收报告模板

- 试用人员与日期：记录试用人员、角色、tenant、机构和日期。
- 平台端试用记录：记录平台端上传、解析、chunk、检索、QA、audit、quota、capability 结果。
- 机构端只读试用记录：记录机构端授权内容查看、检索、QA、citations 和本机构 audit 结果。
- 文件解析样本与失败态：记录文件类型、解析状态、chunk 数、失败态和安全文案。
- 检索、QA、citations 与 audit 记录：记录召回、回答、引用数量、审计编号和低敏状态。
- quota、capability 与 No-Go 核对：记录 quota 结果、capability 状态和 No-Go 清单核对。
- 问题、风险与交接结论：记录问题、风险等级、处理建议和是否可继续试用。

## 失败态处理说明

- 当前文件类型暂不支持解析：记录为预期安全失败，不绕过白名单。
- 文件大小超过解析限制，请拆分后重新上传：记录样本大小和处理建议。
- 文件未提取到可解析文本，扫描件或图片内容暂不支持：记录为预期安全失败，不补做 OCR。
- 知识库文件解析失败，请稍后重试：记录文件类型和页面安全文案，不外显底层异常。
- 解析文本超过长度限制，已截断为低敏预览：记录截断状态和 chunk 预览。
- 当前知识库问答次数已达上限，请稍后再试：记录 quota 命中，不绕过限制。
- 当前账号没有访问该知识库内容的权限：记录账号、tenant、机构和授权范围核对结果。
- 暂无授权可见知识库、无引用、无检索结果均属于可预期试用状态，应记录搜索条件和授权范围。

## 低敏字段和禁止字段

允许展示：知识库摘要、文件低敏元数据、解析状态、失败安全文案、chunk 预览、检索命中摘要、citations、QA audit 摘要、quota 状态和 capability 状态。

禁止展示：存储定位键、文件系统路径、数据库语句、异常堆栈、令牌、密钥、API 凭据、数据库连接信息、模型底层响应、提示词正文、训练内容、向量原文。

## 后续进入真实 AI / OCR / 真实向量库 / runtime 的前置条件

- 真实 AI：必须先完成密钥治理、成本限额、质量评估、安全评估、灰度开关、回滚方案。
- OCR：必须先完成文件安全策略、扫描件识别质量评估、失败补偿、人工复核边界。
- 真实向量库：必须先完成选型、schema/migration 审批、租户隔离、删除回滚、索引重建策略。
- runtime ingestion：必须先完成 worker/queue/scheduler 方案、幂等、重试、死信、可观测性和回滚。
- 任何真实外部服务：必须先完成凭据管理、审计、限流、成本控制和降级策略。
