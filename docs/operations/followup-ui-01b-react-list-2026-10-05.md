## 范围

4 个核心文件：正式随访 page、现有受控随访 Shell、列表查询导航 helper、列表控制组件。另含 3 个测试文件和本验收记录。基于已合并的 FOLLOWUP-QUERY-01；与 V1.1 预览列表 PR 独立。没有改动工作台统计、数据库、迁移、写接口、真实外部系统或部署配置；也没有启动后续批次。

## 页面行为

- URL 保存 `page/pageSize/state/dueBucket/q`，默认 20 条；筛选或容量变更回第一页，翻页保留已提交条件，清除筛选保留容量。
- 兼容工作台 `create=1`、`bucket=today|overdue` 链接；旧到期参数转换为正式契约。重复、未知、冲突或非法参数被拒绝，不调用业务读取器。
- 当前页记录直接来自服务端，不在客户端再次筛选或切片。统计涵盖全部当前匹配任务，不用当前页长度替代总量；状态按钮不呈现未筛选分面的假计数。
- 加载期间隐藏旧任务、统计与写操作；无结果显示 0 / 0。超末页保留真实总数并提供返回末页。缺少可信时区时到期统计显示“—”，普通客户和状态查询仍可用。
- 页面错误不展示旧任务或伪空集。不可用状态提供保留条件的重试及清除筛选；错误信息不透传内部异常。
- 可信导航、机构范围、页面能力和原有权限门禁保持原顺序。共享详情不显示列表控制；新建、认领、改派、流转等 POST/PATCH 参数、幂等键与版本控制逻辑均未修改。
