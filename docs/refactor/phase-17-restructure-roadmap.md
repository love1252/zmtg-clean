## 完成定义

目录重构完成不表示必须移动全部 1509 条迁移矩阵记录。

满足以下条件即可视为最终闭环：

1. 每个纳入范围的文件都有明确职责归属。
2. 每个候选都有明确动作：
   - 迁移；
   - 保持当前位置；
   - 兼容保留；
   - 退役；
   - 受保护；
   - 明确延期。
3. 已实施移动均有调用方修正、验证和回退证据。
4. 不存在未解释的旧路径、重复实现或孤立导入。
5. 数据库和高敏边界可在明确标记为 `protected` 后闭环，
   不要求在本轮强制迁移。

## 全局执行原则

- 一个阶段只处理一个主要领域。
- 正式移动前必须先完成职责、依赖、调用方和回退设计。
- 每阶段创建独立工作分支和本地回退分支。
- 每阶段至少执行：
  `git diff --check`、typecheck、lint、代表性测试和 build。
- build 优先在不含 `.env.local` 的隔离 worktree 中执行。
- PR 默认创建为 Draft。
- 未经明确授权，不转 Ready。
- 未经“合并 #编号”授权，不合并。
- 不批量移动 API 或正式业务源码。
- Schema、Migration、数据库 Client、Seed 和真实凭证继续锁定。
