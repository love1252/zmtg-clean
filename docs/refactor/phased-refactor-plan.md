# 智美天工目录重构计划

## 阶段 1：重构底座

- 保存审计快照。
- 建立交接文档。
- 建立架构边界。
- 生成逐文件迁移矩阵。
- 不移动源码。

## 阶段 2：低风险资产

- scripts 分类。
- Fixture、Demo Seed 分类。
- 本地缓存和临时文件清理。
- 测试目录规则确认。

## 阶段 3：静态资源

- 图片和 Logo 去重。
- 统一品牌资源引用。
- 不改变业务功能。

## 阶段 4：客户、预约、治疗

- 客户中心收口。
- 预约领域收口。
- 治疗摘要领域收口。
- 保持 API 和数据库行为不变。

## 阶段 5：工作台和页面 Shell

- workspace 只保留页面组合能力。
- 页面 Shell 迁回对应业务模块。
- 平台端和机构端保持隔离。

## 阶段 6：随访与触达

- 收口随访任务、路径、消息草稿和安全边界。
- 不接真实发送。
- MessageDelivery 保持统一边界。

## 阶段 7：知识库

- 区分共享知识领域、机构应用、平台治理和存储解析。
- 不修改上传、解析和权限行为。

## 阶段 8：平台端拆分

- 租户。
- 套餐与权益。
- AI Provider。
- 品牌。
- 连接器。
- 审计和用量。

## 阶段 9：API 版本化

- 建立兼容路径。
- 分批迁移调用方。
- 单独 PR 完成。

## 阶段 10：永久架构检查

- dependency-cruiser。
- ESLint import 边界。
- CI 架构检查。
- 最终文档和回归测试。
