## Phase 23 HIS 连接配置写入 payload parser

- 分支：`feat/phase23-his-connection-write-parser`
- 目标：为后续 HIS 连接配置 create / update API 提供可复用的 HTTP payload parser 和最小 DTO helper。
- 完成：
  - 新增 `parseCreateHisConnectionInput`，create payload 只接受 `connectionName`、`sourceSystem`、`vendorType`、`systemType` 四个安全元数据字段，全部必填。
  - 新增 `parseUpdateHisConnectionInput`，update payload 只接受四个安全元数据字段的非空子集。
  - parser 只接受普通 JSON object，拒绝 null、数组、Date、函数、class instance、空原型对象、未知字段、禁止字段、敏感字段别名、非字符串、空字符串、超长字符串和敏感内容。
  - 字符串 trim 后返回，长度限制对齐 repository：`connectionName` 不超过 160，`sourceSystem`、`vendorType`、`systemType` 不超过 64。
  - 新增最小 DTO helper，只返回 create / update v1 允许的四个安全元数据字段。
