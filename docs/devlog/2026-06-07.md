- 当前 main commit：`bba59265c93e20402de829d79bb9c9a2e96ad885`
- 只读盘点结论：
  - 当前 `his_connection_credential_compensation_jobs` 表字段、job state enum、dead letter reason enum、tenant / connection / operationId 复合 FK、operationId unique、调度索引、claim / lock 字段和 retry / nextAttemptAt 字段足以支撑 repository 最小实现。
  - compensation operation repository 可复用可信输入 normalize、tenant + connection + operationId scope、稳定 result、read model 映射、状态流转先查后改、唯一冲突转 conflict 和 repository_error 脱敏模式。

  - 本轮可以不接 service、不实现 worker runtime、不写 audit、不调用 provider、不处理真实凭证。
  - worker claim / lock / stale recovery runtime、compensation audit integration、service 接入、dead letter / manual review 业务闭环和真实 provider / secret manager / HIS adapter 仍需另开 Plan Mode 或独立 PR。
- 完成：
  - 新增 `src/modules/institution/server/his-connection-credential-compensation-job-queue-repository.ts`。
  - 新增 `src/modules/institution/tests/HisConnectionCredentialCompensationJobQueueRepository.test.ts`。
  - repository 方法覆盖 create、get by operation、get by connection、list due、claim due、mark running、mark succeeded、mark failed、requeue、mark dead letter、mark manual review 和 list expired locked jobs。
  - 稳定 result 覆盖 `ok`、`not_found`、`conflict`、`invalid_state_transition`、`validation_failed` 和 `repository_error`。
  - read model 只返回 job queue 表的安全字段，不返回 provider path、secret path、`credentialRef`、idempotencyKey、raw credential、raw HIS payload、request body、response body、provider raw error、SQL、stack 或 `DATABASE_URL`。
  - claim due 只允许到期 queued job 或锁已过期的 claimed / running job，claim 成功写入 `claimed`、`claimId`、`claimVersion + 1`、`claimedBy`、`claimedAt`、`lockedUntil` 和 `updatedAt`。
  - mark running / succeeded / failed / dead letter / manual review / requeue 均校验 `claimId` 和 `claimVersion`，旧 claim 写回返回 `conflict`。
  - 状态流转允许 `queued -> claimed`、`claimed -> running`、`running -> succeeded`、`running -> failed`、`failed -> queued`、`claimed/running/failed -> dead_lettered` 和 `claimed/running/failed -> manual_review_required`。
  - 禁止 `succeeded`、`dead_lettered`、`cancelled` 自动回退。
  - README 和 roadmap 同步本轮 repository 最小边界。
