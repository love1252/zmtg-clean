- 完成：
  - 新增凭证 parser，覆盖 create / update / rotate / clear / revoke payload。
  - create / update / rotate 只接受 `credentialType`、`syntheticPlaceholder`、`idempotencyKey` 和可选 `reasonCode`。
  - clear / revoke 只接受可选 `reasonCode`。
  - parser 只接受普通 JSON object，拒绝数组、null、空字符串、函数、Date、class instance、空原型对象、未知字段和禁止字段。
  - parser 拒绝 body `tenantId`、`credentialRef`、`credentialConfigured`、status、healthStatus、raw HIS payload、external secret path、token、secret、API key、connection string 和真实凭证材料。
  - 新增凭证 service，覆盖 create / update / rotate / clear / revoke 最小 flow。
  - create / update 调用 fake storage 生成安全 `credentialRef` 后调用 repository set。
  - rotate 调用 fake storage 生成安全 `credentialRef` 后调用 repository rotate。
  - clear 调用 repository clear。
  - revoke 调用 repository revoke；当前不强制 storage revoke，因为现有 repository 不暴露内部 `credentialRef` 读取能力，storage revoke 留给后续单独规划。
  - 新增 DTO helper，成功 DTO 只返回 `ok` 和 `credentialConfigured`，错误 DTO 只返回稳定 code / error。
  - README 和 roadmap 同步：凭证 parser / service / DTO 最小实现已完成，下一步进入凭证 API route / permission / audit Plan Mode。
